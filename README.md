# 🌿 PathAble – Accessible Campus Navigator

**Making campus navigation easier, safer, and more inclusive for everyone.**

PathAble is an accessible campus navigation platform designed to help wheelchair users and visually impaired students navigate college campuses more easily. It provides step-free route suggestions, ramp and lift information, voice-guided directions, and accessibility updates.

## 🚩 Problem Statement

Wheelchair users and visually impaired students often face difficulties navigating college campuses because they may not know which routes have ramps, lifts, stairs, or accessible pathways. This makes travelling between classrooms and campus facilities challenging.

## 💡 Our Solution

PathAble provides a simple and user-friendly platform that helps students find accessible campus routes. It offers route options, voice guidance, and lift status updates to support independent campus navigation.

## ✨ Key Features

- **♿ Step-Free Routes:** Find routes that avoid stairs and prioritize accessible pathways.
- **🗺️ Route Finder:** Select starting and destination locations to view suggested routes.
- **🔊 Voice Guidance:** Listen to navigation instructions.
- **🛗 Lift Status Updates:** View lift availability and report lift-related issues.
- **🎨 High Contrast Mode:** Improve visibility with a high-contrast display.
- **🔠 Text Resizing:** Increase text size for better readability.
- **📱 Responsive Design:** Use the website on desktop, tablet, and mobile screens.

## 🛠️ Technologies Used

- **HTML5** – Creates the structure of the website.
- **CSS3** – Provides colourful styling and responsive layouts.
- **JavaScript** – Adds interactive features and route-finding functionality.
- **Browser Speech API** – Supports voice-guided instructions.
- **Local Storage** – Saves demo lift-status updates in the browser.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure these three files are present:
   - `index.html`
   - `style.css`
   - `script.js`
4. Open `index.html` in your browser.
5. Try the route finder and accessibility features.

## ⚠️ Project Scope

This is a working front-end prototype using sample campus locations and route data. It does not currently use live GPS or a real campus map. Lift reports are saved locally in the browser, and verification is demonstrated within the prototype rather than connected to campus staff.
