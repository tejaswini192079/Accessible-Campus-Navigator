💡 How obstacle-aware routing works

  1. PathAble stores the campus as a network of places and connections.
  2. Broken lifts and blocked corridors are removed from that network.
  3. The fastest remaining accessible path is calculated (Dijkstra's algorithm).
  4. If one exists, you get a detour and the reason. If not, you can request staff assistance.

This demo uses sample campus data, not real-time sensors.
